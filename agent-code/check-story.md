| # | 情境 | 預期結果 |

## 四、Final 模式

### 4.1 基本設定與表格產生

| # | 情境 | 預期結果 |
|---|------|----------|
| F01 | 評審數=5、參賽者=4 → 產生表格 | 4列參賽者 × 5欄評審的輸入表 |
| F02 | 更改評審名稱和參賽者名稱 | 結果表顯示自訂名稱 |
| F03 | 評審數=1（極端案例） | 正常運作，過半數=1 |
| F04 | 參賽者=2（最少） | 正常運作，累積欄位為 1→1、1→2 |
| F05 | 參賽者=10（較多） | 正常運作，10個累積欄位 |

### 4.2 輸入驗證

| # | 情境 | 預期結果 |
|---|------|----------|
| F06 | 某評審漏填分數 | 錯誤：「評審 X 的參賽者 Y 未填寫名次」 |
| F07 | 名次超出範圍（如5人比賽填6） | 錯誤：「名次超過範圍 1~N」 |
| F08 | 同一評審給兩個參賽者相同名次 | 錯誤：「評審 X 對 A、B 給了相同名次 N」 |
| F09 | 所有欄位正確填寫 | 計算成功，顯示結果表 |

### 4.3 排名計算正確性（核心邏輯）

| # | 情境 | 預期結果 |
|---|------|----------|
| F10 | 基本排名：B隊在 1→1 就達到過半，A隊在 1→2 才達到 | B隊排第一，A隊排第二 |
| F11 | 同欄達過半，票數不同（情境1） | 票數較多者排前 |
| F12 | 同欄、同票，加總不同（情境2） | 加總較小（更好名次）者排前 |
| F13 | 加總也相同，比下一累積欄（情境3） | 下一累積欄票數較多者排前 |
| F14 | 完全一致，Battle 決勝（情境5） | 比較兩選手在每位評審中誰排更前 |
| F15 | 過半欄位高亮標記（框框） | 結果表中首次過半的累積欄醒目標記 |

### 4.4 具體數值驗證

| # | 情境（5評審、4參賽者） | 預期名次 |
|---|----------------------|----------|
| F16 | A:[1,2,1,3,2], B:[2,1,3,1,1], C:[3,3,2,2,3], D:[4,4,4,4,4] | B>A>C>D |
| F17 | 平局情境：兩選手所有評審分數完全相同 | 顯示並列或battle結果 |
